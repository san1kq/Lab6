### Описание
Программа на языке C, демонстрирующая использование условного оператора `if-else`, логических операций и тернарной операции:

* **Задача 1:** проверка, является ли введённый год високосным (по остатку от деления на 4 и по точному условию с учётом 100 и 400).
* **Задача 2:** вычисление значения кусочной функции:
  $$F(x) = \begin{cases} x^2 - x, & \text{при } 0 \le x \le 1 \\ x^2 - \sin(\pi x^2), & \text{при } x > 1 \text{ или } x < 0 \end{cases}$$
  *(вывод результата выполнен с помощью тернарной операции)*.
* **Задание 3:** определение чётных разрядов (единиц, десятков, сотен, тысяч) введённого четырёхзначного числа.
* **Домашнее задание:** определение знака Зодиака по дате, введённой одним числом `ddmm`, без использования `if-else`.
